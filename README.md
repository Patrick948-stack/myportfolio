# Patrick Mulikuza — Personal Portfolio

My personal corner of the internet. Built with plain HTML, CSS, and JavaScript — no frameworks, no build tools, just code.

The site covers what I've been working on: frontend projects, data visualizations, hardware experiments, research in ML and physics, and a few websites I built for friends. There's also a research section with papers I've written for class or personal projects, ranging from relativistic photography to cell phone radiation safety.

## What's inside

- **About** — a bit about me, my skills, experience, and education
- **Services** — what I can help with: frontend dev, data visualization, and research
- **My Work** — projects with screenshots and links to GitHub or live sites
- **Research & Writing** — academic and personal papers, all available to read as PDFs
- **Contact** — a form that goes straight to my inbox

HTML · CSS · JavaScript · Font Awesome
